Роутер (public/index.php)
Этот файл обрабатывает запросы пользователей и перенаправляет их соответствующим контроллерам.


<?php
// Загружаем автозагрузчик классов
require_once '../vendor/autoload.php';

// Настройка маршрута и инициализация приложения
$uri = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
$routes = require('../app/routes.php');

if (!isset($routes[$uri])) {
    header('HTTP/1.1 404 Not Found');
    exit();
}

list($controllerClass, $actionMethod) = explode('@', $routes[$uri]);

$controllerInstance = new $controllerClass();
$controllerInstance->$actionMethod();
Контроллеры (controllers/*Controller.php)
Контроллер получает данные от модели и передает их представлению (view). Пример простого HomeController:


<?php
class HomeController
{
    public function index()
    {
        include __DIR__.'/../views/home/index.php';
    }
}
Пример ProductController, который выводит список товаров:


<?php
use App\Models\Product;

class ProductController
{
    private $productModel;
    
    public function __construct() {
        $this->productModel = new Product();
    }

    // Отображение списка продуктов
    public function listProducts()
    {
        $products = $this->productModel->all();
        include __DIR__.'/../views/products/list.php';
    }

    // Просмотр отдельного товара
    public function showProduct($id)
    {
        $product = $this->productModel->findById($id);
        
        if (!$product) {
            http_response_code(404); die("Страница не найдена");
        }

        include __DIR__.'/../views/products/view.php';
    }
}
Модели (models/*.php)
Модели работают непосредственно с базой данных и обеспечивают доступ к данным. Пример модели продукта:


<?php
namespace App\Models;

class Product
{
    protected static $dbh;

    public function __construct() {
        self::$dbh = new PDO(
            'mysql:host='.DB_HOST.';dbname='.DB_NAME,
            DB_USER,
            DB_PASS,
            array(PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION)
        );
    }

    public function all()
    {
        return self::$dbh->query('SELECT * FROM products')->fetchAll(PDO::FETCH_ASSOC);
    }

    public function findById($id)
    {
        $stmt = self::$dbh->prepare('SELECT * FROM products WHERE id=:id');
        $stmt->execute(['id'=>$id]);
        return $stmt->fetch(PDO::FETCH_ASSOC);
    }
}

Маршрутизация (routes.php)
Файл маршрутов связывает URI с соответствующими действиями контроллеров:


<?php
return [
    '/'              => 'App\Controllers\HomeController@index',
    '/products'      => 'App\Controllers\ProductController@listProducts',
    '/product/{id}'  => 'App\Controllers\ProductController@showProduct'
];
